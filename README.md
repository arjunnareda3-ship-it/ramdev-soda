# 🥤 RAMDEV SODA - Cold Drinks Shop Website

A complete web application for managing a cold drinks business with customer store and admin panel.

## Features

### 🛍️ Customer View
- Browse all available cold drinks
- View drink prices and descriptions
- Beautiful card-based layout
- Responsive design for all devices

### 🔐 Admin Panel
- **Add Drinks**: Add new drinks with name, icon, price, and description
- **Edit Drinks**: Modify existing drink details
- **Delete Drinks**: Remove drinks from the menu
- **Manage Prices**: Update prices anytime
- **Password Protected**: Secure admin access

## How to Use

### For Customers
1. Open `index.html` in your browser
2. Browse all available drinks
3. Click "Order Now" to place an order

### For Admin
1. Click on "🔐 Admin Panel" button
2. Enter Password: `admin123`
3. Add, Edit, or Delete drinks
4. All changes are saved automatically

## Technical Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Storage**: Browser LocalStorage (no database needed)
- **Responsive**: Mobile-friendly design
